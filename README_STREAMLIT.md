# Calculadora de Ingeniería Económica – versión web

Archivos para publicar en Streamlit Community Cloud:

- `streamlit_app.py`: interfaz web.
- `calculator_engine.py`: motor financiero y analizador de ejercicios.
- `requirements.txt`: dependencias.

## Publicación

1. Cree un repositorio en GitHub.
2. Suba estos tres archivos en la raíz del repositorio.
3. Ingrese a Streamlit Community Cloud e inicie sesión con GitHub.
4. Seleccione **Create app / Deploy an app**.
5. Elija su repositorio.
6. En **Main file path** use: `streamlit_app.py`.
7. Pulse **Deploy**.
8. Streamlit generará una URL pública terminada en `.streamlit.app`.

No es necesario subir la versión de Tkinter/Spyder para que la aplicación web funcione.
